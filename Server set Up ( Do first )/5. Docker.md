Docker ( Both Docker Engine and Docker Compose are needed )

a ) Docker Engine

 Set up and install Docker Engine from Docker apt repository.

https://docs.docker.com/engine/install

!!!! IMPORTANT !!! CHANGE THIS FILE IN ORDER TO SUPPORT " memory / cpu limits " in you docker websites ( see the yaml file of the " site-music-developer.yaml " )

1. sudo nano /boot/cmdline.txt ( depends on system)
2. . Add these parameters to the END of the existing line (don't create a new line): cgroup_enable=memory cgroup_memory=1

So if your line looks like: console=serial0,115200 console=tty1 root=PARTUUID=xxx rootfstype=ext4 ...

It should become: console=serial0,115200 console=tty1 root=PARTUUID=xxx rootfstype=ext4 ... cgroup_enable=memory cgroup_memory=1

3. sudo reboot
