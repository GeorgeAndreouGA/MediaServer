# Docker Engine & Compose Setup

Both **Docker Engine** and **Docker Compose** are required.

## 1. Install Docker Engine

Install from the official Docker apt repository:
https://docs.docker.com/engine/install

## 2. Enable cgroup memory/CPU limits

Required for `mem_limit` / `cpus` (or `deploy.resources.limits`) to work in compose files.

```bash
sudo nano /boot/cmdline.txt   # path varies by system/distro
```

Append the following to the **end of the existing line** — do not create a new line:

```
cgroup_enable=memory cgroup_memory=1
```

For example, this line:

```
console=serial0,115200 console=tty1 root=PARTUUID=xxx rootfstype=ext4 ...
```

becomes:

```
console=serial0,115200 console=tty1 root=PARTUUID=xxx rootfstype=ext4 ... cgroup_enable=memory cgroup_memory=1
```

Then reboot:

```bash
sudo reboot
```

## 3. Managing disk usage

Check how much space Docker is using:

```bash
docker system df      # summary
docker system df -v   # verbose breakdown
```

**Safe** — clears the build cache only:

```bash
docker builder prune -a
```

**Use with caution** — removes every image not referenced by a running *or stopped* container:

```bash
docker image prune -a
```
