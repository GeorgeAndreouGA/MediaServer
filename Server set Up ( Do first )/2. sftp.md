# SFTP-Only User

> **User model:** this server uses three account tiers for defense in depth:
>
> - **A regular SSH user** — created during OS install, has full shell access, no root privileges.
> - **An SFTP-only user** — created below, chrooted, file-transfer access only, no shell.
> - **`root`** — every service is installed and run as root. If you don't use `sudo`, a service installs only for the current non-root user, which is not what we want — root is used deliberately so every service lives in one consistent, tightly controlled place.
>
> Root SSH login itself stays disabled (see [SSH Hardening](<3. ssh.md>)); you `ssh` in as the regular user and elevate with `su - ` ( needs the root password and not the user's password since it is not ( and must not be ) in the suders group ) from there.

## 1. Create the SFTP-only user

```bash
sudo adduser <sftpuser>
sudo passwd <sftpuser>
```

## 2. Create the chroot directory

```bash
sudo mkdir /mnt/<foldername>
```

## 3. Restrict SFTP in `sshd_config`

Edit the config:

```bash
sudo nano /etc/ssh/sshd_config
```

- If the **regular user should keep shell access but lose SFTP access**, disable the default SFTP subsystem:
  ```
  Subsystem sftp /bin/false
  ```
- At the end of the file, restrict the SFTP user to SFTP only, chrooted, with no tunneling:
  ```
  Match User <sftpuser>
      ForceCommand internal-sftp
      PasswordAuthentication yes
      ChrootDirectory /mnt/<foldername>
      PermitTunnel no
      AllowAgentForwarding no
      AllowTcpForwarding no
      X11Forwarding no
  ```

## 4. Set correct ownership and permissions

OpenSSH requires the chroot root directory to be owned by `root` and not writable by the SFTP user, or it will refuse the connection:

```bash
sudo mkdir -p /mnt/<foldername>/<name>
sudo chown root:root /mnt/<foldername>
sudo chmod 755 /mnt/<foldername>
sudo chown <sftpuser>:<sftpuser> /mnt/<foldername>/<name>
```

## 5. Restart SSH

```bash
sudo systemctl restart ssh
```

## 6. Mount the external drive

Format the external drive to **exFAT** first, then mount its partition (not the whole disk) into the SFTP directory created in step 4:

```bash
lsblk
sudo mount /dev/<partition> /mnt/<foldername>/<name>
```

## 7. Mount automatically on boot

```bash
sudo blkid
sudo nano /etc/fstab
```

Add:

```
UUID=<uuid-from-blkid> /mnt/<foldername>/<name>  auto  defaults  0  2
```

## 8. Test

```bash
sftp <sftpuser>@<your-server-ip>
```

Password is the one set in step 1. Alternatively, connect with FileZilla using the same credentials.
